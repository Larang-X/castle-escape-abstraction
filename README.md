# 🏰 맵 탈출 게임으로 추상화 배워보기 (Castle Escape Abstraction)

> **2022 개정 교육과정 중학교 『정보』 교과 연계 비영리 교육 연구용 소프트웨어**  
> **핵심 학습 주제**: III. 알고리즘과 프로그래밍 — **추상화(Abstraction)**를 활용한 복잡한 문제 분해 및 최적 경로 탐색

---

## 📌 1. 프로그램 개요 및 교육적 목표
본 소프트웨어는 중학교 학생들이 어렵게 느끼는 **알고리즘의 '추상화(Abstraction)'** 개념을 흥미진진한 2D 고딕 고성 탈출 어드벤처 게임을 통해 자연스럽게 체득할 수 있도록 설계된 교육용 웹 애플리케이션입니다.

- **1단계: 탈출 방해물 가지치기 (불필요한 정보 제거 / Pruning)**
  - 복잡한 맵에 배치된 수많은 막다른 방, 미끼 함정, 비효율적인 우회로를 분석하여 탈출에 불필요한 노이즈 요소를 소거합니다.
- **2단계: 핵심 요소 추출 및 경로 배제 분석 (Extract & Filter)**
  - 탈출에 꼭 필요한 핵심 방(Node)과 방 사이의 구간별 소요 시간(Edge weight)을 도출하고, 특정 통로를 배제한 논리적 근거를 서술합니다.
- **3단계: 최적 탈출 경로 및 총 소요 시간 도출 (Optimal Path Synthesis)**
  - 추출된 핵심 네트워크(가중치 그래프)를 종합하여 출발지부터 탈출구까지의 최단 탈출 순서와 총 소요 시간을 연산하고 최적해를 도출합니다.

## 🎮 2. 스테이지 구성 및 맵별 학습 요소

| 스테이지 | 테마 및 배경음악 | 핵심 추상화 학습 포인트 |
| :--- | :--- | :--- |
| **MAP 1: 용암 지하성당** | *Lava Catacombs Theme* | 상층 보물실(막다른 길)과 하단 화산암 우회로(7분 지연)를 소거하고, 성소 교각(D)을 거치는 6분 최적 경로 도출 |
| **MAP 2: 빙하 수로 미궁** | *Emerald Mist* | V자 심층 수로에서 설인 폭포다리(5분 지연)와 막다른 얼음방을 배제하고, 수직 승강기(E)를 활용한 7분 최단 경로 도출 |
| **MAP 3: 기계 시계탑** | *Gears of Fortune* | 중앙 구름다리 붕괴 조건을 분석하여 서쪽 종탑 우회로를 배제하고, 중앙 태엽 승강기(F)로 수직 상승하는 8분 경로 도출 |
| **MAP 4: 심연 최종 탈출** | *Abyssal Escape Theme* | 상층 폐쇄 철문(통행 불가)과 강제 역송 마법진(W)을 완벽히 가지치기하고, 대성문 수문장 교각을 돌파하는 8분 탈출로 완성 |

## 📂 3. 심사위원 제출 및 파일 구성 안내

본 프로젝트는 순수 웹 표준 기술(HTML5, Canvas, Web Audio API, Vanilla JavaScript)로 제작되어 **별도의 플러그인이나 프로그램 설치 없이 웹 브라우저(Chrome, Edge, Safari, Whale 등)에서 즉시 실행**됩니다.

### 심사위원이 확인해야 할 핵심 파일:
1. **`index.html`** (메인 게임 및 학습지 인터페이스)
   - 게임 실행 파일입니다. 더블 클릭하여 웹 브라우저로 열면 즉시 게임과 학습지가 시작됩니다.
2. **`assets/`** (에셋 폴더)
   - `assets_bundle.js`: 109종의 도트 스프라이트 및 타일맵 리소스 번들 파일
   - `audio/`: 맵별 배경음악(BGM) 및 효과음(SFX) 오디오 파일 (mp3, wav)
3. **`Code.js` & `appsscript.json`** (클라우드 데이터 연동 백엔드)
   - 학생별 학습지 답안(1~3단계) 및 스테이지 클리어 기록을 실시간으로 구글 스프레드시트(Google Sheets)에 수집·채점하는 구글 앱스 스크립트 코드
4. **`README.md`** (소프트웨어 설명서 및 심사 안내서)

> ⚠️ **주의 사항 (로컬 파일 실행 시)**:  
> 모바일 스마트폰이나 태블릿에서는 보안 정책상 `file:///` 프로토콜을 통한 로컬 파일 접근이 차단되므로, **스마트폰에서 구동하려면 웹 서버 환경(예: GitHub Pages 배포 링크)**으로 접속해야 모든 그래픽과 사운드가 정상 작동합니다.
